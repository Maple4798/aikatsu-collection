# アイカツ！アンコール カードコレクション管理アプリ

受講番号：6th-44
氏名：藤武彩羽

## 1. プロダクトの紹介

「アイカツ！アンコール」のカードをコンプリートするための、
カードコレクション管理Webアプリケーションを作成しました。

カードを集めていると、
「どのカードを持っているのか」
「あと何を持っていないのか」
が分かりにくくなるため、一目で所持状況を確認できるアプリを作成しました。

主な機能は以下の通りです。

- 全85種類のカードを一覧表示
- 未所持カードは半透明、所持カードは通常のカラーで表示
- カードごとの所持枚数を「＋」「－」ボタンで管理
- ミニ一覧表示と通常表示の切り替え
- タイプ・レアリティ・ブランド・カテゴリ・所持状況による絞り込み検索
- カードをクリックすると詳細情報を表示
- 全体コンプリート率の表示
- タイプ別コンプリート率の表示
- レアリティ別コンプリート率の表示
- 総プレイ回数の表示
- 合計使用金額の表示
- 自分が引いたカードのレアリティ別排出割合の表示

カード情報、所持枚数、プレイ履歴などはデータベースで管理しています。

## 2. こだわった点・苦労した点

- 未所持のカードを半透明にし、入手するとカラー表示になるようにして、持っているカードと持っていないカードを一目で判別できるようにした
- 85枚のカードを確認しやすくするため、「ミニ一覧」と「大きく見る」の2種類の表示方法を用意した
- ピンクと白を中心に、カードコレクションに合う可愛いデザインになるようにした
- カードの所持枚数と実際にプレイした回数を別々に管理した
- 所持枚数を減らした場合でも、それまでに使った金額やプレイ回数は減らないように、所持情報とカードを引いた履歴を別のテーブルで管理した
- カードを1枚ずつ登録すると時間がかかるため、CSVファイルからカード情報をまとめてデータベースへ登録できるようにした
- カード画像とカード情報を紐づけて、一覧画面と詳細画面の両方で画像を表示できるようにした

## 3. 操作方法

1. カード一覧画面を開く
2. 「ミニ一覧」または「大きく見る」を選択してカードを確認する
3. カードの「＋」ボタンを押すと所持枚数が1枚増える
4. 未所持だったカードを入手すると、半透明表示から通常のカラー表示に変わる
5. 「－」ボタンを押すと現在の所持枚数を減らすことができる
6. タイプ・レアリティ・ブランド・カテゴリ・所持状況を選択し、「検索」ボタンを押すとカードを絞り込める
7. カード画像をクリックすると詳細画面が表示され、タイプ・レアリティ・ブランド・カテゴリなどを確認できる
8. 左側のメニューから「全体コンプリート率」「タイプ別」「レアリティ別」を選択すると、それぞれのコンプリート状況を確認できる
9. 「回数・使用金額」を選択すると、総プレイ回数と合計使用金額を確認できる
10. 「自分の排出割合」を選択すると、レアリティごとの排出割合を確認できる
